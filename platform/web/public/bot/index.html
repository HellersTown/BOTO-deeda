WaystockBot

WaystockBot is the crawler behind Skeuos, an auction search app that started in Wisconsin. It reads public auction listings so that buyers can find sales near them, and it sends every one of them to the auction's own page to bid.

How it names itself

Every request carries this User-Agent, and nothing else stands in for it:

WaystockBot/0.1 (+https://waystock.org/bot)

It never sends a browser's User-Agent and never retries a refused request in disguise.

What it reads

  • Only sites whose terms allow it, or whose operator has given written permission. Sites that forbid automated collection are left alone and only linked to.
  • Public listing facts: a sale's or lot's title and description, its price and bid count where shown, its close time, its pickup town and its link.
  • Never anything behind a login. It has no accounts, never bids, and collects nothing about bidders.
  • Street addresses and phone numbers written into a listing's description are not kept.

How it behaves

  • It reads robots.txt before each run and obeys it, including Crawl-delay.
  • It makes one request at a time to a site, several seconds apart, and most sites are read about once an hour.
  • A block is an answer. It never works around a CAPTCHA, a bot challenge or a refusal. It stops and records it.
  • Where a site offers an API or a feed, it uses that instead of pages.

How to turn it away

Add this to your site's robots.txt. WaystockBot stops at its next run, within the hour:

User-agent: WaystockBot
Disallow: /

To slow it down instead, add Crawl-delay: 30 (seconds between requests) to the same group.

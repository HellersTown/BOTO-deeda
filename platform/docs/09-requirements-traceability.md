# Requirements traceability

This document re-checks every instruction the owner has given against what actually exists. It was first written on 2026-09-28, when the owner asked for "a recheck of every prompt and make sure your current direction is focused". It was brought up to date on 2026-10-01, when the owner made Wisconsin Surplus the first priority for a resale business run with this tool, again on 2026-10-02, when the owner asked for search to be the strongest feature (row 40), and on 2026-10-05, when the owner asked for more volume, photo matching and an hourly price watch (row 41).

**Status legend**

| Status | Meaning |
|---|---|
| **DONE** | Built and verified against real data or a real system. |
| **PARTIAL** | Some of it exists; the rest is named explicitly. |
| **IN PROGRESS** | Being built now. |
| **LATER** | Sequenced behind something it depends on. |
| **BLOCKED** | Needs the owner, or an outside party, to act. |

"Verified" always means run against production or a live site, never against a fixture written from documentation. Documentation-based testing is how the GSA adapter once passed 24 tests while returning zero real lots.
